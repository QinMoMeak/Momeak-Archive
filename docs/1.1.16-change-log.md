# 工作说明 1.1.16

- 版本号：1.1.16
- 生成时间：2026-08-28

## 本次改动摘要
- 后端存储层从"直接读写 JSON/MD 文件"升级为 SQLite（`node:sqlite`，零原生依赖），补全增删改查的数据库持久化。
- SQLite 成为运行时唯一写入源，每次写操作后自动镜像回 `data/*.json` 与 `content/**/*.md`，GitHub Pages 静态构建与 Git 提交工作流完全不变。
- API 层新增按 id 的 GET 单条路由（含 markdown），PUT/DELETE 路由正则补上遗漏的 `songs` 模块。
- 新增 `scripts/migrate-json-to-db.mjs` 幂等迁移脚本（支持 `--force` 强制重建），输出条数与抽样字段比对报告。
- 首次启动数据库为空时自动从 JSON 种子初始化，无需手工迁移步骤。

## 主要修改文件
- server/db/database.mjs（新增：SQLite 连接、schema 初始化、JSON 自动种子）
- server/knowledge-store.mjs（存储层切换为 SQLite 实现，对外导出函数签名保持不变）
- server/knowledge-api.mjs（新增 GET 单条路由；PUT/DELETE 正则补 songs）
- scripts/migrate-json-to-db.mjs（新增：幂等迁移 + 比对报告）
- .gitignore（忽略 data/momeak.sqlite 及 WAL 文件）
- .env.example（新增 KNOWLEDGE_API_PORT / KNOWLEDGE_REPO_ROOT / KNOWLEDGE_DB_FILE）
- README.md（从 Vite 模板残留改写为真实架构说明）
- docs/1.1.16-change-log.md

## 数据库 Schema
- `entries(module, id, name, category, status, tags, payload, created_at, updated_at, position)`：主键 `(module, id)`；`payload` 存完整条目 JSON（兼容五模块字段差异与 TS 类型联合）。
- `markdowns(module, entry_id, content)`：主键 `(module, entry_id)`，外键级联删除。
- `taxonomy(id=1, payload)`：单行 JSON 存分类元数据。

## 功能变化
- 本地开发模式下增删改查全部落库，数据不再直接写 JSON 文件（JSON/MD 由镜像机制同步，内容与之前完全一致）。
- 导入导出、AI 解析、WebDAV 同步、分类管理功能不受影响（均经由 knowledge-store 的同签名函数）。

## 可能的影响范围
- 依赖 `data/*.json` 的静态构建流程不变；线上只读站点行为不变。
- `.gitignore` 新增忽略 SQLite 文件后，仓库不会提交运行时数据库。

## 后续建议
- 若后续数据量增大，可把 `payload` 中的高频筛选字段（category/status/tags）拆为独立列并建索引。
- 可考虑在导出 zip 时顺带打包 SQLite 快照，作为二进制级备份。
